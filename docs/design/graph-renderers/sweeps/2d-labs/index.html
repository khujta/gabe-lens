2D graph-library labs Every lab renders the SAME committed example estate through a different renderer. Nothing is a mock: each page loads templates/center/shell/example/codebase-graph-station/c4-graph.js, flattens it with the shared feed.js, and reports its own measured numbers in the right rail. All bundles are vendored under vendor/; every page opens from file:// with the network off.

libraries deliberately given no lab

react-flow / xyflow — every node is a real DOM element with React reconciliation behind it. That is exactly right for a 20-node editable flow editor and exactly wrong for 1,384 read-only nodes: no canvas, no WebGL, no batching. Its performance page offers no node-count guidance at all — the advice is React.memo, hiding subtrees, and simplifying CSS. The one virtualisation prop, onlyRenderVisibleElements, is documented in the API reference but a maintainer has warned it can make things slower, because a node re-initialises every time it scrolls back into view. It also brings React as a hard dependency into a vanilla, file://-loaded page. Node editor, not graph viewer.
Konva — same category as PixiJS but Canvas2D-only with a per-shape scene graph; you would be hand-rolling exactly what the d3+Canvas lab hand-rolls, plus a shape-object allocation per node. PixiJS covers the "custom renderer" slot with a GPU path, so it got the lab.
Graphistry — GPU rendering happens on a server and arrives as a streamed session in an iframe. There is no offline artifact to vendor. Disqualified by the file://-no-network constraint before any feature comparison.
KeyLines / ReGraph (Cambridge Intelligence), Ogma (Linkurious), yFiles for HTML (yWorks) — commercial, per-developer/per-deployment licences, no public npm artifact to download and no build obtainable without a sales conversation. They are the strongest products in this space on hulls, layouts and labelling (yFiles in particular has the only genuinely good orthogonal/hierarchical edge routing), and they are the right answer if this were a product being sold. For a vendored, offline, MIT-shaped suite artifact they cannot be evaluated here at all — no lab is possible, not merely inconvenient.

how to run

Open any lab-*.html directly from the filesystem. No server, no network, no build step. Each lab's right rail reports the numbers it measured on YOUR machine — the table above is this host (WSL2, swiftshader, 1500×900).
