Graph-library labs — Sweep A (2D)

Seven candidate libraries, one feed, one chrome. Every lab loads lab-feed.js — 1,384 nodes · 4,053 edges · 20 entity groups, derived by build-feed.py from the committed example estate (templates/center/shell/example/codebase-graph-station/c4-graph.js) — and renders it with nothing but a vendored local bundle. No CDN, no network, opens from file://.
Read the FPS column as a RANK, not a rating. Every number below was measured by probe.mjs under system Chrome with --use-gl=swiftshader — software GL, no GPU. That is the same handicap for all seven, so the ordering is meaningful; the absolute numbers on a machine with a GPU will be several times higher, and the WebGL labs gain the most from that.

A green boot is not a render. During this sweep the sigma lab reported 60 fps with afterRender firing 90 times over 86 frames — while drawing nothing at all. Only the screenshot caught it. So probe.mjs photographs every stage, fails a lab whose PNG is smaller than a blank page compresses to, and retries once when a draw looks suspiciously empty. Trust the pictures below, not the events.

Scale: add ?dup=N to any lab (or node probe.mjs --dup=3) to replicate the whole feed N times — ×3 is 4,152 nodes / 12,159 edges, past the onyx estate's ~3.9k.

what each lab is actually testing

ruled out without a lab

  • react-flow / xyflow (MIT, 38.3k★, v12.11.6) — a node editor: every node is a React DOM element, which is why it wins at custom node UI and loses at 1,384 of them. Its own discussions recommend a canvas renderer past ~100 nodes. Wrong instrument: we render a map, not an editor.
  • Konva (MIT, 14.8k★) — a 2D canvas scene graph with no graph model, no layout, and no picking beyond shape hit-tests. Everything the d3-force + PixiJS lab hand-writes, you would hand-write again with less GPU batching. PixiJS covers this branch.
  • Graphistry — GPU rendering, but server-side: the client streams frames/data from a Graphistry server. Incompatible with a file:// page that must open with no network.
  • KeyLines / Ogma / yFiles — commercial, per-developer licences (yFiles list price starts at $17,000/developer/year; KeyLines and Ogma are quote-only). All three are excellent and all three fail the same test: the suite ships these pages inside other people's repos.
  • @cosmograph/cosmos — CC-BY-NC-4.0, non-commercial. Do not vendor it. The lab below uses @cosmos.gl/graph, the OpenJS Foundation fork of the same engine, which is MIT.

how to re-run

  • python3 build-feed.py — regenerate lab-feed.js from the example estate (deterministic; byte-identical on an unchanged source).
  • node probe.mjs — boot every lab under headless Chrome, assert no network request leaves the page, screenshot the stage as render proof, write probe-results.json and shots/.
  • node probe.mjs lab-sigma.html — one lab.
