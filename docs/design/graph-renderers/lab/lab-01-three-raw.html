lab-01 · raw three, everything instanced Glyphs: one InstancedMesh per form (≤11 draws). Badges: one atlas quad layer. Bubbles: one sphere layer. Labels: one canvas atlas + billboard quads. Wires: one LineSegments per CONN kind (7), per-vertex colour, the kind's dash. Particles: one Points layer. Hulls: ConvexGeometry per entity + sub. Picking: a colour-id pass over nodes, then over link segments (1×1 readback).
Layout: d3-force-3d + the adapter's zForce in a Blob-URL worker (?worker=0 on-thread) · ?layout=baked · ?walk=1 first-person (click to lock, WASD/QE, collides with the buildings) · ?ships=1 not built yet (the stretch row). The view itself is three-view.js, shared with lab-04.
