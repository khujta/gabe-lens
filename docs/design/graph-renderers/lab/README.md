# Graph-renderer labs — one feed · one adapter · one probe

**Swiftshader caveat, first:** every number here was measured under headless system Chrome with `--use-angle=swiftshader` (CPU rasterisation,
NO GPU) on this WSL2 host. fps and frame ms are comparable BETWEEN pages and UNDER-state the draw-call gap a real GPU would show; read them as a
rank. Draw calls, entity purity, picking correctness and the tier-press law are the deciding columns.

Design record: [../plan.md](../plan.md) · the sweeps this lab was cut from: [../sweeps/](../sweeps/) · chooser: [index.html](index.html).

## Rails

| file | role |
|---|---|
| `feed-loader.js` | picks the fixture from `?feed=` and writes the `<script>` tags (file:// has no fetch) |
| `adapter.js` | THE adapter: `window.GABE_FEED` — nodes · links · ents · anchors · tiers · `seedPositions()` · `force()` (the station's zForce) · `applyBaked()` · `selfTest()` |
| `scorecard.js` | `window.__LAB` + `LAB.*` + the `LABG` probe surface every page registers (`setTier` · `positions` · `screenOf` · `pick` · `pickLink` · `stats` · `settled`) |
| `probe.mjs` | the ONE measurement rail (offline proof · ink · picking · tier-press law · heap · bundle split · R10 grep · purity · README regen) |
| `run.sh` | disk guard → adapter self-check per fixture → every page × fixture, one Chrome at a time |
| `vendor.sh` | exact pins → `vendor/` + `MANIFEST.json`; refuses `@cosmograph/cosmos`; three r185 is read from the station's own bundle |
| `fixtures/fetch-onyx.sh` | copies the tier3 center feeds into `fixtures/onyx/` (gitignored, ruling D3) |
| `bake-fdp.py` · `layouts/` | graphviz `fdp` + nested entity>sub cluster subgraphs → `window.GABE_BAKED[fixture]` / `[fixture:fn]` (`?layout=baked`), deterministic (`start=1`, byte-identical); fdp segfaults intermittently on this feed → 3 retries |
| `three-kit.js` | the instanced three.js toolkit: one draw call per layer (glyph forms · badge atlas · label atlas · wires per CONN kind · particles), the station's hull, an orbit rig, colour-id picking (nodes first, wires second) |
| `three-view.js` | the SHARED raw-three view (lab-01 · lab-04): layers + hulls + picking + cards + walk mode + the LABG surface; a page supplies positions and calls `V.sync()` |
| `adapter.py` | the Python twin of the adapter (the baker reads it); if the two ever disagree, `adapter.js` is the law |
| `debug.mjs` | `node debug.mjs <page> "<query>"` — one headless load that prints page errors WITH stacks (a look, never a measurement) |

Knobs on every page: `?feed=example|onyx` · `?scale=full|core|x2|x4|x8` · `?layout=live|baked` · `?tier=0..3` · `?fn=1` · `?fe=0` · `?inject=1`.
Page knobs: lab-00 `?hollow=1` · `?particles=0` · `?conns=0`; lab-01 `?worker=0` · `?walk=1` · `?ships=1` (not built); lab-02 `?layout=fa2` · `?redraw=0`; lab-03 `?layout=fcose` (core only) · `?webgl=1`; lab-04 `?ticks=N` · `?cluster=0.6`.

**Settle is measured in TICKS, not wall clock.** The wrapper's own default (`cooldownTime` 15,000 ms) stops the engine after ~17 ticks at 1 fps — the
station ships that default, so on a slow GPU its layout freezes mid-way. Every lab page runs 240 ticks (cosmos: `?ticks`, default 120 — it ticks once per its own render frame) and reports the
tick count at settle or at the probe's timeout; lab-00's per-tick cost (connectors + hulls rebuilt every third tick, the station's way) is minutes under
swiftshader, so its row reads `>400 s at tick N`.
